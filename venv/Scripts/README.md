# Local Windows virtual-environment scripts

These files were copied from the owner's local `C:\sigilchainproj\venv\Scripts`
directory at their request. They are environment-specific launchers and
activation scripts, not the SigilChain application source or a portable Python
environment. The `.exe` launchers depend on the matching Python installation
and packages; prefer recreating an environment from the repository's
`requirements.txt` on another machine.
